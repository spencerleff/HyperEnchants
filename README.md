# Hyper Enchants

**Hyper Enchants** is a Spigot plugin for Minecraft that adds a complete custom enchantment system while remaining fully compatible with the vanilla Minecraft client. Originally developed for **Minecraft 1.17**, it may also function on newer versions.

## Features

### ✨ 70+ Custom Enchantments

* Over **70 unique custom enchantments**.
* Enchantments are divided across **5 rarity tiers**, providing progression and variety.
* Includes:

  * Weapon-specific enchantments
  * Armor-specific enchantments
  * Universal enchantments that can be applied to multiple item types

### 📚 Custom Enchantment Generation

* Custom enchantments can be obtained directly through the **vanilla enchantment table**.
* Enchantments are generated randomly, making each enchanting session unique.

### 🧙 Enchanter System

Use the `/enchanter` command to access the Enchanter GUI.

Features:

* Purchase enchantment books from different rarity tiers.
* Books generate a random enchantment within the selected tier.
* Right-click a purchased book to reveal its enchantment.

### 🔨 Tinkerer System

Use the `/tinkerer` command to access the Tinkerer.

Features:

* Exchange unwanted custom-enchanted gear for experience.
* Provides a useful way to recycle items and recover value.

### ⚔️ Real-Time Combat & Armor Effects

* Custom enchantments are handled through real-time event processing.
* Armor and weapon effects activate dynamically during gameplay.

### 🪓 Grindstone Compatibility

* Remove custom enchantments using the vanilla **Grindstone**.
* Integrates naturally with existing Minecraft mechanics.

### 📖 Enchantment Book Combining

* Combine enchantment books directly in your inventory.
* If two books contain the same enchantment and level, they can be merged to create a book one level higher.
* Allows players to progressively upgrade powerful enchantments.

## Commands

| Command      | Description                                                         |
| ------------ | ------------------------------------------------------------------- |
| `/enchanter` | Opens the Enchanter menu for purchasing custom enchantment books.   |
| `/tinkerer`  | Opens the Tinkerer menu to exchange enchanted items for experience. |
| `/hyper`     | Main plugin command.                                                |
| `/bless`     | Plugin utility command.                                             |

## Compatibility

* Designed for **Spigot 1.17**
* Functions on a **vanilla Minecraft client**
* May be compatible with newer Minecraft versions

## Summary

Hyper Enchants expands Minecraft's enchanting system with dozens of custom enchantments, rarity-based progression, custom enchantment books, item recycling, enchantment upgrading, and seamless integration with vanilla gameplay mechanics.
